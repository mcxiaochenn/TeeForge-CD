# 可复用踩坑记录

## 2026-09-02：Linux ZIP 不能用 tar 检查

- 范围：xtask 跨平台模块打包。
- 现象：Linux 四 ABI 和 WebUI 都构建成功，但 ZIP 复核报告缺少 `.sha256`。
- 错误假设：默认 `tar -tf` 能读取所有平台创建的 ZIP。
- 根因：Windows 的 `tar` 可处理该归档，而 Linux GNU tar 不负责 ZIP 目录读取。
- 正确处理：Windows 使用 `tar -tf`，Linux/macOS 使用 `unzip -Z1`。
- 验证方式：远端 CI 的 Four-ABI package、Dev Build 和 Artifact 上传均成功。
- 防止复发：跨平台归档检查必须按主机工具能力分支，并在 CI 实跑验证。
- 关联提交：`4f9ba5c`。
- 状态：已修复。

## 2026-08-03：公开文档不得暴露 Keybox 维护细节

- 范围：文档和 AI 上下文管理。
- 现象：公开文档可能让不了解上下文的维护者直接复现私密解码流程。
- 错误假设：把完整维护链路写入架构文档便于所有人查阅。
- 根因：公开架构说明与私密维护手册没有分层。
- 正确处理：公开文档只写数据流、安全边界和验证要求，具体维护资料放入 Git 忽略的 `docs/private/`。
- 验证方式：私密文件被 Git 忽略，公开索引不包含算法、密钥或派生细节。
- 防止复发：新增文档前先判断内容是否属于公开架构、内部运维或私密维护。
- 关联提交：`a7fd758`、`fc25eea`。
- 状态：持续遵守。

## 2026-08-03：下载非空不代表响应有效

- 范围：Keybox 下载和 CDN 同步。
- 现象：非空 HTTP 404 响应可能被当作有效数据继续解码。
- 错误假设：只要下载结果非空就可以进入解码流程。
- 根因：未同时检查真实 HTTP/进程退出状态和内容格式。
- 正确处理：检查下载器退出码、大小上限和 `AndroidAttestation` 内容标记。
- 验证方式：无效响应 fixture 被拒绝，失败时保留旧文件。
- 防止复发：所有外部下载都必须做状态、大小和格式三重检查。
- 关联提交：`ddee09c`。
- 状态：已修复。

## 2026-07-14：Android 工具和权限不能凭桌面环境假设

- 范围：模块脚本、设备兼容性和权限。
- 现象：设备可能没有 `openssl`，递归权限设置可能覆盖二进制执行权限。
- 错误假设：桌面 Linux 工具和修改前的文件权限会在 Android 安装器中保持可用。
- 根因：Android 用户空间精简，Magisk 安装阶段会重新设置权限。
- 正确处理：使用 Rust `sha2`/toybox `sha256sum`，并在 `set_perm_recursive` 后重新设置可执行权限。
- 验证方式：四 ABI 构建和安装脚本静态检查；真机结果仍需单独记录。
- 防止复发：涉及设备命令或权限时先查目标环境，再写兼容回退。
- 关联记录：`docs/history/2026-07-14-retrospective.md`。
- 状态：持续遵守。
